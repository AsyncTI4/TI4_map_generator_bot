# 86 Supernova

Source: https://tirules2.com/R_supernova (Living Rules Reference 2.0 text plus tirules2 notes)

### Rules Reference

A supernova is an anomaly that affects movement.

86.1 A ship cannot move through or into a supernova.

### Notes (tirules2 clarifications)

I. If a ship finds itself in a supernova by some uncommon game effect, it may remain there and move out without harm.
II. A future rule change will place the ship movement restrictions of anomalies upon all units.
