# 57 Move (Attribute)

Source: https://tirules2.com/R_move (Living Rules Reference 2.0 text plus tirules2 notes)

### Rules Reference

Move is an attribute of some units that is presented on faction sheets and unit upgrade technology cards.

57.1 A unit’s move value indicates the distance from its current system that it can move during the Movement step of a tactical action.

### Notes (tirules2 clarifications)

I. When an effect moves a unit to an adjacent system, modifying that unit’s move value will have no effect.
