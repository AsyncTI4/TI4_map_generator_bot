# 9 Anomalies

Source: https://tirules2.com/R_anomalies (Living Rules Reference 2.0 text plus tirules2 notes)

> **Designer FAQ:** any units moving into, through or out of anomalies follow the ship rules for
> anomalies, including units moved by Mahact's Benediction or ground forces committed with G'hom Sek'kus.

### Rules Reference

An anomaly is a system tile that has unique rules.

9.1 An anomaly is identified by a red border located on the tile’s corners.
9.2 There are four types of anomalies: asteroid fields, nebulae, supernovas, and gravity rifts.
a. Some anomalies contain planets; those systems are still anomalies.
9.3 Each type of anomaly is identified by its art. See rulebook for images.
9.4 Abilities can cause a system tile to become an anomaly; that system tile is an anomaly in addition to its other properties.
9.5 Abilities can cause a system to be two different anomalies; that system has the properties of both anomalies.

### Notes (tirules2 clarifications)

I. An empty system is not an anomaly.
II. A system containing a wormhole is not an anomaly.
III. A system with a Vuil’raith Dimensional Tear is a gravity rift, and thus an anomaly.
